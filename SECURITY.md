# Security

This is a static, client-only proof of concept: no backend, no accounts, no
data leaves your browser. It is still served with a strict security header set
(see [`public/_headers`](public/_headers)).

If you find a problem, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/richardthornton/redact-calc/security/advisories/new)
rather than opening a public issue.
